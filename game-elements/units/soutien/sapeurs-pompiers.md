# Sapeurs-pompiers

## Identité

- Catégorie : soutien — Contrôle : [O]
- Rôle : lutte contre l'incendie, secours, désincarcération, décontamination.
- Statut : militaires à Paris (BSPP) et à Marseille (BMPM), civils ailleurs.

## Armement

- Aucun (pompiers civils) ; armement individuel possible pour les pompiers militaires.

## Équipement

- Fourgons-pompes, camions-citernes, échelles.
- Appareils respiratoires, matériel de désincarcération.

## Besoins logistiques

- Eau non potable, en grande quantité.
- Carburant : gazole routier — consommation : moyenne.
- Santé : matériel médical.
- Vivres : rations de combat, eau potable.

## Interactions

- Coopère avec les [Canadair](../aerien/canadair.md).
- Peut intervenir sur les incendies provoqués par les armes incendiaires du joueur.

## Face aux zombies

- Aucun rôle de combat ; un incendie non maîtrisé peut détruire une ville reconquise.
