# Canadair (CL-415)

## Identité

- Catégorie : aérien — Contrôle : [A]
- Rôle : bombardier d'eau (Sécurité civile).

## Versions

- Canadair CL-415.

## Postes

Équipage individuel, non contrôlable à bord.

- Pilote, copilote.

## Ordres possibles

- Trajet par waypoints, avec point d'écopage (lac, mer).
- Axe de largage : droite de longueur arbitraire le long de laquelle l'eau est larguée.

## Armement

- Aucun.

## Équipement

- Réservoir d'eau, écopage en vol.

## Besoins logistiques

- Carburant : Jet A-1 ou F-34 — consommation : élevée.
- Eau non potable (écopée sur un plan d'eau).
- Maintenance : moyenne.

## Mobilité

- Écope sur l'eau sans se poser.

## Interactions

- Coopère avec les [sapeurs-pompiers](../soutien/sapeurs-pompiers.md) et les [Dash 8](dash8.md).

## Face aux zombies

- Aucun effet de combat ; empêche les incendies (y compris ceux causés par le joueur) de ravager une ville ou une forêt.

## Décisions

- Le feu est simulé objet par objet (chaque arbre, chaque objet), y compris pour des incendies de la taille d'une ville comme Bordeaux. Voir [SYSTEMES.md](../../systemes/SYSTEMES.md).
- Les Dash 8 bombardiers d'eau ont leur propre fiche : voir [Dash 8](dash8.md).
