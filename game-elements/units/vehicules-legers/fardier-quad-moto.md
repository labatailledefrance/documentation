# Fardier, quad et moto

## Identité

- Catégorie : véhicule léger — Contrôle : [D]
- Rôle : éclaireurs rapides, transport léger de matériel.

## Versions

- Fardier, quads et motos en service : à recenser.

## Postes

Chaque occupant est un soldat contrôlable individuellement.

- Pilote.
- Un passager (selon le véhicule).

## Armement

- Aucun ; les occupants utilisent leurs armes individuelles.

## Équipement

- Remorque (fardier, quad).

## Besoins logistiques

- Carburant : F-34 ou essence selon le modèle — consommation : très faible.
- Maintenance : pièces détachées, pneus.

## Mobilité

- Très rapide, passe partout ; aucune protection.
- Transportable par : hélicoptères, A400M, C-130.
- Classe d'itinéraire : véhicule léger ([classes d'itinéraire](../UNITS.md#classes-ditinéraire)).

## Interactions

- Ravitaillé par : [camions logistiques](camions-logistiques.md).

## Face aux zombies

- Parfait pour reconnaître ou porter un message ; mortel si le pilote est encerclé.

## Décisions

- Les véhicules civils récupérés sont inclus : voir [Véhicules civils](vehicules-civils.md).
