# Serval (VBMR léger)

## Identité

- Catégorie : véhicule léger — Contrôle : [O]
- Rôle : transport de troupes léger, reconnaissance, liaison.

## Versions

- VPB (véhicule de patrouille blindé).
- MCT (missile de combat terrestre, Akeron MP).
- LAD (lutte anti-drones).
- Défense sol-air (Mistral).
- Génie.
- NRBC.
- Renseignement / guerre électronique.
- Liste à vérifier et compléter.

## Postes

Chaque occupant est un soldat commandable individuellement.

- Pilote.
- Chef de bord.
- Passagers : un groupe d'infanterie réduit.

## Armement

- Tourelleau téléopéré : mitrailleuse de 7,62×51 mm OTAN ou de 12,7×99 mm.
- Selon la version : missiles antichars Akeron MP, missiles Mistral, armement anti-drones.

## Équipement

- Radio, système de partage d'information SCORPION.

## Besoins logistiques

- Carburant : F-34 — consommation : faible.
- Munitions : 7,62×51 mm OTAN ou 12,7×99 mm.
- Maintenance : pièces détachées, pneus.
- Vivres de l'équipage et des passagers.

## Mobilité

- 4×4.
- Transportable par : A400M.
- Classe d'itinéraire : camion ([classes d'itinéraire](../UNITS.md#classes-ditinéraire)).

## Interactions

- Transporte : infanterie.
- Ravitaillé par : [camions logistiques](camions-logistiques.md).

## Face aux zombies

- Bonne mobilité ; le tourelleau téléopéré permet de tirer sans exposer de soldat.

## Décisions

- Toutes les versions sont incluses (règle générale : chaque version de chaque véhicule).
