# LRU (lance-roquettes unitaire)

## Identité

- Catégorie : véhicule lourd — Contrôle : [D] pour le déplacement ; tir sur ordre.
- Rôle : frappes de précision à longue portée.
- Statut 2030 : peu d'exemplaires, roquettes non renouvelables.

## Versions

- Version unique.

## Postes

Chaque occupant est un soldat contrôlable individuellement.

- Pilote.
- Tireur.
- Chef d'engin.

## Armement

- Roquettes guidées de 227 mm (GMLRS).

## Équipement

- Conduite de tir, navigation GPS.
- Radio.

## Besoins logistiques

- Carburant : F-34 — consommation : élevée.
- Munitions : roquettes de 227 mm (GMLRS) ; quasiment impossibles à produire en France.
- Maintenance : chenilles, pièces détachées.
- Vivres de l'équipage.

## Mobilité

- Chenillé.
- Transportable par : porte-chars, train, navire.
- Classe d'itinéraire : chenillé lourd (à affiner : bien plus léger qu'un Leclerc) ([classes d'itinéraire](../UNITS.md#classes-ditinéraire)).

## Interactions

- Tire sur coordonnées ou sur désignation d'un JTAC.

## Face aux zombies

- Précis mais charge unitaire : gaspillage contre une horde. Utile pour détruire un pont ou un bâtiment précis.

## Décisions

- Son successeur FLP-T n'est pas inclus dans le jeu.
