# Buffalo

## Identité

- Catégorie : véhicule lourd (génie) — Contrôle : [D]
- Rôle : véhicule protégé d'ouverture d'itinéraire : inspection et levée des engins explosifs.

## Versions

- Version unique. Liste à vérifier.

## Postes

Chaque occupant est un soldat contrôlable individuellement.

- Pilote.
- Chef d'engin.
- Sapeurs embarqués.

## Armement

- Mitrailleuse d'autodéfense.

## Équipement

- Bras articulé d'inspection.
- Caméras.

## Besoins logistiques

- Carburant : F-34 — consommation : élevée.
- Munitions : 7,62×51 mm OTAN ou 12,7×99 mm.
- Maintenance : pièces détachées, lubrifiants et liquides techniques ; réparation en atelier.
- Vivres de l'équipage.

## Mobilité

- 6×6 à roues, très protégé contre les mines.
- Classe d'itinéraire : camion ([classes d'itinéraire](../../UNITS.md#classes-ditinéraire)).

## Interactions

- Travaille avec les [sapeurs](../../infanterie/sapeur.md).
- Constructions possibles : voir [CONSTRUCTIONS.md](../../../constructions/CONSTRUCTIONS.md).
