# SPRAT (système de pose rapide de travures)

## Identité

- Catégorie : véhicule lourd (génie) — Contrôle : [O]
- Rôle : pose de ponts d'assaut pour franchir les coupures (rivières, canaux, fossés, ponts détruits).

## Versions

- Version unique. Liste à vérifier.

## Postes

Chaque occupant est un soldat commandable individuellement.

- Conducteur.
- Chef d'engin.

## Armement

- Aucun (armement individuel de l'équipage).

## Équipement

- Travures (éléments de pont) posées et récupérées par le véhicule.

## Besoins logistiques

- Carburant : F-34 — consommation : élevée.
- Maintenance des travures.
- Maintenance : pièces détachées, lubrifiants et liquides techniques ; réparation en atelier.
- Vivres de l'équipage.

## Mobilité

- Camion à roues ; transportable par navire et train.
- Classe d'itinéraire : camion (masse à vérifier) ([classes d'itinéraire](../../UNITS.md#classes-ditinéraire)).

## Interactions

- Travaille avec les [sapeurs](../../infanterie/sapeur.md).
- Constructions possibles : voir [CONSTRUCTIONS.md](../../../constructions/CONSTRUCTIONS.md).

## Face aux zombies

- Permet de franchir une coupure, mais aussi de la refermer derrière soi ; les zombies franchissent toutefois les cours d'eau.
