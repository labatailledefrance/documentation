# Dépanneurs et porte-chars

## Identité

- Catégorie : véhicule lourd — Contrôle : [O]
- Rôle : récupération des véhicules immobilisés, transport des engins lourds sur longue distance.
- Modèles : dépanneur de char Leclerc (DCL), dépanneurs à roues, tracteurs porte-chars.

## Versions

- Dépanneur de char Leclerc (DCL).
- Dépanneurs à roues.
- Tracteurs porte-chars.
- Liste à recenser.

## Postes

Chaque occupant est un soldat commandable individuellement.

- Pilote / conducteur.
- Chef d'engin.
- Mécaniciens.

## Armement

- Mitrailleuse d'autodéfense (selon le modèle).

## Équipement

- Grue, treuil, outillage de dépannage.
- Plateau porte-char.

## Besoins logistiques

- Carburant : F-34 — consommation : élevée.
- Maintenance : pièces détachées ; transporte aussi des pièces détachées pour les autres véhicules.
- Vivres de l'équipage.

## Mobilité

- Chenillé (DCL) ou à roues (porte-chars, routier).
- Classe d'itinéraire : porte-char chargé quand il transporte un char, camion à vide ; chenillé lourd pour le DCL ([classes d'itinéraire](../UNITS.md#classes-ditinéraire)).

## Interactions

- Dépanne : chars, engins du génie, tous véhicules lourds.
- Économise le carburant et l'usure des chenilles sur les longs trajets.

## Face aux zombies

- Aucun rôle de combat ; un char récupéré vaut mieux qu'un char abandonné.

## Décisions

- Les réparations se font en atelier, pas sur place : les dépanneurs ramènent les véhicules. Voir l'atelier de maintenance dans [CONSTRUCTIONS.md](../../constructions/CONSTRUCTIONS.md).
